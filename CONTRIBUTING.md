# Contributing

Contributions that improve reconstruction reliability, editability, semantic
correctness, PowerPoint compatibility, or cross-platform verification are
welcome.

Before opening a pull request:

1. Keep the installable skill self-contained under `skills/img2pptx/`.
2. Do not add user images, confidential material, API keys, or copyrighted
   examples without explicit redistribution rights.
3. Keep `SKILL.md` concise and move detailed protocols to `references/`.
4. Validate the skill with the built-in `skill-creator` validation workflow.
5. Test material workflow changes on at least one realistic raster-to-PPTX task.
6. Report actual audit results; do not hard-code successful QA outcomes.

When adding examples, prefer original, synthetic, or public-domain references
and document their provenance.
