# Security Policy

Do not include credentials, private source images, confidential diagrams, or
generated artifacts containing sensitive information in issues or pull requests.

To report a security issue, use GitHub's private security advisory feature for
this repository. Include the affected skill version, runtime environment, and a
minimal reproduction that does not expose sensitive data.

Users remain responsible for reviewing commands, dependencies, input-image
rights, and generated PPTX contents before sharing or publishing them.
